# AI Career Companion

## Project Overview

AI Career Companion is an AI-based system designed to help students with the internship application process.

The system focuses on understanding a student's profile from their resume and storing the extracted information in a structured format. This structured candidate information can later be used for internship matching, skill-gap analysis, cover letter generation, interview preparation, and career assistance.

## Milestone 1

Milestone 1 focuses on the foundation and candidate understanding part of the system.

### Implemented Features

- Student profile creation
- Student personal and educational information collection
- Resume PDF upload
- Resume text extraction using PyPDF2
- Structured candidate profile creation
- Candidate profile storage in JSON
- Basic result/profile display
- System architecture documentation
