# AI Agent Responsibilities

## 1. Job-Resume Matching Agent

### Responsibility
Compares the candidate's structured profile with internship or job
requirements.

### Main Functions
- Analyze candidate skills and experience.
- Analyze job requirements.
- Identify matching skills.
- Provide a compatibility assessment.

---

## 2. Skill Gap Agent

### Responsibility
Identifies the skills that a candidate is missing for a specific internship
or job role.

### Main Functions
- Compare candidate skills with required skills.
- Identify missing technical and soft skills.
- Suggest areas for improvement.
- Help the candidate create a learning plan.

---

## 3. Resume Agent

### Responsibility
Processes and assists with the candidate's resume.

### Main Functions
- Extract information from resumes.
- Analyze resume content.
- Identify missing or weak information.
- Suggest improvements to the resume.

---

## 4. Cover Letter Agent

### Responsibility
Helps generate personalized cover letters based on the candidate profile
and the target internship or job.

### Main Functions
- Use candidate skills and experience.
- Consider the target job requirements.
- Generate a personalized cover letter.
- Allow the candidate to improve or customize the generated content.

---

## 5. Interview Agent

### Responsibility
Helps candidates prepare for interviews.

### Main Functions
- Generate interview questions.
- Create questions based on the candidate's skills and projects.
- Provide interview preparation guidance.
- Support technical and behavioral interview preparation.

---

## 6. Career Assistant

### Responsibility
Acts as a general career assistance agent for the student.

### Main Functions
- Answer career-related questions.
- Provide personalized career guidance.
- Help students understand suitable career paths.
- Use the candidate profile to provide relevant suggestions.

---

## Agent Interaction

The AI agents will use the structured candidate profile as an important
source of candidate information.

Future versions of the system can use RAG to retrieve relevant information
from job descriptions and other knowledge sources before the agents generate
responses.

The agents are defined at the architectural level in Milestone 1. Their
complete implementation will be developed in later milestones.
